# My Workspace - Chinese Style Personal Site

This is a personal website built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, customized with a Chinese ink wash painting aesthetic.

## Features
- **Chinese Style Design**: Custom CSS for ink wash backgrounds, KaiTi fonts, and traditional colors.
- **Profile Mode**: Custom homepage layout with a hero image and navigation grid.
- **Responsive**: Adapts to mobile and desktop screens.

## Deployment

This site is configured for deployment on [Vercel](https://vercel.com).

### Manual Deployment Steps
1. Push changes to GitHub.
2. Connect the repository to Vercel.
3. Ensure the **Root Directory** is set to the project root (default).
4. Vercel will automatically build using `hugo --gc --minify`.

## Local Development
1. Install Hugo.
2. Run `hugo server` to start the local development server.
